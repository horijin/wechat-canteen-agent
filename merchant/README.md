# 食堂商家端微信小程序

## 快速开始运行

1. 注册并登录微信开发者平台，选择“创建小程序”，按照指引完成创建流程，并获取可用于开发部署微信小程序的App ID（或测试号App ID） 
2. 下载并在桌面端配置微信开发者工具，按照指引使用微信开发者工具导入本目录，需要将`project.config.json` 中的App ID参数替换为测试者的App ID。
3. 项目代码默认服务开放在`http://127.0.0.1:8000`。在联调本机服务时，需要根据实际后端服务部署的 IP 和外网暴露端口的配置情况进行修改。需确认在微信开发者工具中的项目配置栏已关闭“合法域名校验”。
4. 在微信开发者工具选择调试模式，会出现模拟手机UI界面，点击编译按钮，即可在电脑端微信开发者平台进行手机仿真调试、运行。也可点击“真机调试”按钮进行调试。
5. 正式发布必须使用已备案 HTTPS 域名，并在微信公众平台为相应服务配置合法域名。
6. 若后端服务尚未部署，前端服务可连接部署在校内东风云服务器上的示例服务，并调用相关API。示例服务暴露在 `114.214.241.72:13200`。

## 目录

```text
app.js / app.json / app.wxss   应用入口、路由和全局样式
config/                        环境默认值
utils/                         请求、存储、格式化、业务常量
services/                      后端 API 适配层
components/                    空状态、订单卡片
pages/login/                   档口选择与服务配置
pages/dashboard/               经营工作台
pages/orders/                  订单中心
pages/order-detail/            订单详情与状态流转
pages/menu/                    今日菜单、价格、库存、停售
pages/settings/                服务检测、提醒偏好、切换档口
docs/                          架构与后端补齐说明
```

## 配置

默认后端开放的 API 地址位于 `config/env.js`。运行时在登录页或设置页修改后，会写入微信本地存储并覆盖默认值。
	以下为本地环境运行为例，实际开发、测试和生产环境下需要切换为真实 IP 和外网暴露端口。

```js
module.exports = {
  defaultApiBaseUrl: "http://127.0.0.1:8000",
  requestTimeout: 12000,
  orderPollingMs: 5000
}
```
